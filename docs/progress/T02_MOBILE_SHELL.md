## 实现范围

按用户给定 Muse 布局参考，使用米白/常青绿、原创“小忆”伙伴、左右气泡与来源样式入口。
主导航依用户要求为聊天/我的回忆/提醒，右上进入个人设置、左上进入聊天历史；登录页壳可预览。
最新反馈已将原双层输入区改成约 60px 单行：加号、文字输入、语音/发送按钮，无独立工具栏和说明行。
未接入业务的页面及对话明确标注预览，发送只显示尚未发送，不制造模型回答或保存成功。
语音按钮点击告知暂未开放，未调用麦克风、图片或外部 API。
18/20/22px 阅读字号通过 uni-app storage 跨页面持久化；草稿仅内存跨导航保留。
组件与平台层分离；H5 原生输入标签适配在 platform/accessibility.ts，不将 DOM 操作散落业务代码。
使用 Lucide 静态 SVG，随资源保留完整许可；未复制未许可仓库代码或 Muse 角色。
头像只显示真实等待状态、轻微呼吸，支持减少动态效果；其他状态留给真实服务状态驱动。
