## 新增的强制实现边界

1. 记忆保留 L0 原文，L1 结构化事实与来源，L2 事件关联；相对时间保存原表达和精度，不补造日期/医院/严重性。
2. MemoryExtractor/Repository/Retriever/Updater/ContextBuilder/Evaluator 按任务实际实现，避免先造一堆空模块。
3. Synthetic 生成器参数：用户数、数量、种子、时间跨度、类别、重复/冲突/无效比例；只导入独立测试库，生成/导入可重现，Git 只保留小样本、脚本和报告。
4. 固定题集至少 200，覆盖精确召回、换会话/重登录、语义改写、矛盾、未知、删除、隔离和性能；不以同一 LLM 自评作为客观正确性证据。
5. 输出 Recall@5、Top1、事实回答正确率/幻觉率、冲突准确率、泄漏/删除召回数、P50/P95、并发/查询/内存，以及真实 API 耗时/token/估算费。目标 90%/80%/95%/零泄漏/零删除召回/P95≤2s，结果以实际评估为准。
6. 检索只选择有限上下文，不能把万条数据塞进 Prompt。先用 MySQL 结构化/关键词基线，实测不足再决定是否需要向量索引。
7. Prompt 集中版本化：对话、抽取、冲突、记忆回答、意图、安全；每版用途、输入/输出 Schema、样例、变更。修改相关 Prompt 要重跑原评估并保留对比。
8. 真实模型只做受控小样本；自动回归、万级生成/评估用 Mock/确定性算法，不能批量烧 API。
