# V0.1 模块与数据路径

uni-app/Vue3/TypeScript的H5首先运行；FastAPI和独立MySQL为持久事实源。微信/Android保留平台层；仅H5经过当前可运行验收，App工程合同不等于已打包或真机通过。

- apps/mobile/src/platform：网络、输入、导航、导出、推送适配；页面不持有运营Key。
- services/api/app/api/v1：认证/聊天/记忆/任务/地图/通知/导出HTTP接口。认证身份决定用户归属，不信任客户端user_id。
- llm/providers.py及services/model_chat.py：Mock/官方DeepSeek、共享MySQL日预算、幂等和用量。原文先存，再一次请求合并回复/记忆候选/意图，未知不盲目重试。
- memory：提取、Repository、SQL检索、Updater、有限ContextBuilder、固定题集Evaluator；最多5记忆/12KB上下文，非全库拼Prompt。
- tasks：有证据的候选草案、时间澄清、确定性计算、用户确认与版本化生命周期。
- maps：明确位置授权/候选选择、固定第三方域名、日限/缓存/幂等收据；实际高德未接通验证。
- notifications/worker.py：独立进程扫MySQL outbox，以锁和租约领取；版本/取消/设备权限过滤，有限明确失败重试，unknown不重发。Mock/供应商接受均非送达。

数据分层：L0 messages原文；L1 memory_facts+memory_sources有来源事实、时间精度、授权、状态与修订；L2当前为来源关联的派生时间线，不生成无依据叙事摘要。删除长期记忆后检索/引用排除，原始聊天不被随意覆盖。

数据库当前20张表（含alembic_version）：users/auth_sessions；conversations/messages；memory_facts/sources/uses/revisions/life_events；task_drafts/outing_tasks/reminders/notification_jobs/devices/task_audit_logs；model_usage/budget；map_requests/budget。模型与真实索引/FK见services/api/app/models/entities.py及Alembic迁移；用户归属复合约束、消息/任务请求唯一键和列表/领取索引由迁移验证。

数据库仅silver_memory_demo_v01与silver_memory_demo_v01_test，loopback:13306/silver_demo白名单；任何ALE_AI_MySQL或任意未知schema在连接前被拒绝。UTC DATETIME(6)存储、任务保留IANA时区；H5香港默认。

确认信息与安排任务分开。任务/reminder/outbox同事务落库；地点修改新草案确认后同事务取消旧待发job并存新任务，旧原文/审计保留。第三方在途发送不在MySQL事务内，不能保证撤回或exactly-once。

迁移：在项目services/api执行项目Python的alembic upgrade head；开发环境不得自动downgrade/base或清卷。可丢弃测试库迁移往返已测试；P05独立测试库逻辑备份恢复已通过，开发库覆盖恢复与真实推送对账未验收；不以用户JSON导出替代。
