# ADR-003：CR-001 主动生活助理与 Android 交付

- 时间：2026-10-26（Asia/Hong_Kong）
- 状态：采纳用户 CR-001；技术方案待对应任务实际验证。
- 覆盖：ADR-001 仅站内提醒裁剪、ADR-002 以 PC 作为最终通知验收的决定。
- 不改写：原任务书、冻结 V1.0 基线、既有提交和 ADR 的历史描述。

## 职责与执行链

保留现有 uni-app H5/Vue3/TS 与 FastAPI/MySQL，不重建工程。
DeepSeek 的结构化输出只生成 TaskDraft：意图、原始时间表达、时间含义候选、地点候选与缺失字段；Pydantic 校验后再由服务追问。
“十点去”不能默认到达；“我家/张阿姨家”仅可使用本人明确授权且未撤回的地点别名。
预览卡可编辑；未确认、不完整/过期的卡不会生成有效调度。
用户确认时提交幂等键、卡片版本和经确认字段；服务端重验权限与时间，不接受客户端计算值作为事实。

高德服务经后端固定域名/路径调用，不接受模型任意 URL 或代码。地图/天气失败可保存明确时刻的普通提醒，显式移除未有依据的车程/带伞结论。
路线数据记录单位、交通方式、来源与获取时间；一天前的车程标参考，临近出门才有限刷新。
高德天气是行政区及预报日期维度，不能写成某住址某分钟必然下雨；超过供应商预报范围就显示尚无预报。

## 时间计算

存储 UTC 时间与用户 IANA 时区。相对日期以用户当地日期和解析参考时间计算，卡片展示完整日期/时间/时区。
用户明确到达时：建议出门 = 目标到达 - 车程 - 接驳/步行缓冲 - 弹性缓冲；提醒 = 建议出门 - 提前量。
用户明确出发时：建议出门 = 用户指定出发时刻；不能再次减车程。提醒仍减用户确认提前量。
缓冲、提前量非负且可编辑；过期、跨日、夏令时重叠/缺失、可能来不及时提示确认/调整，不让 LLM 运算决定入库值。
CR 示例数值只用于合成计算测试，35 分钟/09:00/08:30 不得冒充实时查询。

## 持久调度

选择 MySQL 驱动的有限独立 Python Worker，先不额外引入 Redis/Celery 或第二套调度存储。
业务任务、对应 reminder 与 outbox notification_jobs 在同一事务确认/更新；数据库为待发任务唯一事实源。
Worker 以锁/短租约领取到期 job，发送前核对 task revision、取消/完成状态和授权；启动后重扫持久记录。
唯一幂等键涵盖用户、任务、修订、通知用途、设备；同一确认/重试不创建重复有效 job。
修改/取消在事务内使旧修订的未来 job 失效，再按新修订建待发 job。
外部发送不是数据库事务：请求结果不明时进入待核对状态，不能盲目重发；只对可确认的暂时失败有限重试。
不承诺外部推送 exactly-once；供应商已接受的消息是否能撤回取决于通道，不能隐瞒取消时已在途的状态。
停机错过的提醒按有效期处理，过时任务标 expired/missed 并站内可见；恢复扫描策略在 T11C 落成测试后记录，不无限补发。

## Android 通知接入

保留平台适配层。H5 只做 UI/接口和通知中间验证，不替代 Android 后台测试。
优先 uni-push 2.0 厂商通道；依据官方文档，其标准云端 SDK 位于 uniCloud。
主业务与 Worker 仍在 Python/MySQL；通过最小服务端鉴权桥接调用 uniCloud 推送扩展库。
桥接应限制允许的操作、时间戳/重放窗口、设备归属、幂等请求和超时；客户端无权直接发服务端推送。
打包 App 必须启用对应原生推送模块及厂商参数；标准 HBuilder 调试基座的在线演示不能当离线通道验收。
AppID/包名/签名/厂商通道/云服务部署与费用在 T11D 明确后实施，缺授权标 BLOCKED_PROVIDER_CONFIGURATION，不绕过。

通知公开状态区分 queued、sent_to_provider、delivered_if_confirmed、failed、opened，补充 cancelled/expired/unknown 解释。
服务商返回成功只代表接受请求；缺送达回执显示“已提交服务商，送达未确认”。真机实际观察与平台回执分别保留证据。
设备 ID 仅服务端受限存储/加密，客户端不跨用户复用；退出/撤回时停止绑定，日志与 Git 不记录实际设备标识。
真实通知标题尽量不暴露地址/健康等隐私；点击后鉴权访问本人行程。

官方依据：[uni-push 2.0 概述、离线推送和服务端调用](https://uniapp.dcloud.net.cn/unipush-v2.html)、[高德路线](https://lbs.amap.com/api/webservice/guide/api/newroute)、[高德天气](https://lbs.amap.com/api/webservice/guide/api-advanced/weatherinfo)。
