# ADR-001：V0.1 范围与工程底座

- 日期：2026-10-26
- 状态：采用

V0.1 以用户任务书为独立执行合同；八份冻结 V1.0 基线尚未提供，未自行补写。
先交付 H5，使用 uni-app Vue3/TypeScript，服务端使用单体 FastAPI、SQLAlchemy/Alembic 和本项目独立 MySQL。
T01 只实现可启动骨架与验证流水线；T02 实现四 Tab 与视觉，T03 实现健康接口/数据库迁移，之后按顺序增加业务。

本期核心为隔离测试用户、有来源的长期记忆、跨会话召回、纠错/删除、时间线和站内提醒。
语音、照片/生成影像、家属共享、复杂向量检索、多 Agent 和正式跨端上架延后。
2026-10-26 用户新增主动生活助理要求：电脑浏览器通知及真实路线/天气查询进入首版，
由 ADR-002 覆盖原先仅站内提醒的裁剪；手机后台提醒仍延后。
模型通过服务端 Provider 接入，自动测试使用明确标注的 Mock，真实调用在 T06 配置后验证。

前端以 DCloud 官方 vite-ts 模板兼容版本为依据，按实际发布的依赖包和许可证锁定。
uni-app 使用 apps/mobile/src 作为源码目录；其下保留 pages/components/api/stores/styles/platform 分层。
平台存储、网络和通知在 T02 及对应业务任务中封装，不预先制作空接口冒充能力。

独立 Compose 项目名 silver-memory-demo-v01，数据库 silver_memory_demo_v01，默认本机 127.0.0.1:13306。
密码由本地未跟踪 .env 提供；不使用已有 ALE_AI_MySQL，不连接未知数据库，不暴露公网端口。
T01 仅验证 Compose 配置，T03 才启动数据库并验证迁移。

模型名称和计费将在 T06 查阅官方文档，.env.example 中候选名称不代表已核验可用。
main 仅保留稳定历史；dev/v0.1 每任务独立提交并验证远端 SHA，最终由用户审核 PR 合并。
