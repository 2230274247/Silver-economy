## 需求变更

产品是“有长期记忆的 AI 生活助理，同时保存人生故事”。
出行执行闭环与有来源的跨会话记忆并列 P0：意图 → 必要追问 → 路线/天气 → 确定性计算 → 可编辑确认卡 → 用户确认 → MySQL/持久化调度 → 真机通知 → 修改/取消/完成。
“已保存”“已调度”“已提交推送服务”“实际送达”必须分别记录，不能用文字承诺或绿勾替代。
高德 Web 服务优先提供地点/路线/天气，DeepSeek 只提取意图/字段，Python 负责计算和调度。
最终必须有一台真实 Android 手机退到后台/关闭页面后收到通知的证据；H5 和浏览器通知只作中间测试。
用户对 T02 的最新输入栏要求优先于原件中“宽大输入区”的建议：保持单行约 60px。

## 预计成本与控制

- 全量自动测试用 Mock，不在 CI 注入真实服务 Key。
